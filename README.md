# عربيات القاهرة

لعبة قيادة ميكروباص على طرق القاهرة والدائري. نسخة Canvas ثنائية الأبعاد مع مهرجان وراديو مصر.

## التشغيل

افتح `index.html` في المتصفح، أو من المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## التحكم

- يمين/شمال للتوجيه
- زر المهرجان للموسيقى
- زر الراديو لراديو مصر
- كلاكس، كاميرا، إضاءة، فرامل، دفعة

التقدم والرصيد محفوظان محلياً على الجهاز.
